# Sistema de Avaliação da Mostra Extensionista

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema para auxiliar o processo
de avaliação de trabalhos acadêmicos apresentados na Mostra Extensionista.

O sistema tem como objetivo apoiar professores avaliadores durante a avaliação
dos trabalhos, permitindo o cadastro de trabalhos, organização das sessões,
associação de avaliadores e registro das avaliações.

## Objetivo

Desenvolver uma solução que torne o processo de avaliação dos trabalhos mais
organizado, simples e eficiente, permitindo que os avaliadores realizem as
avaliações por meio do sistema.

## Atores do sistema

O sistema possui os seguintes atores principais:

- **Administrador:** responsável pela carga de professores e projetos e pelo
  gerenciamento dos professores.
- **Coordenador:** responsável pelo cadastro das sessões, configuração dos
  critérios, associação dos avaliadores aos trabalhos e consulta dos resultados
  gerais.
- **Orientador:** responsável pelo cadastro dos trabalhos para avaliação e
  consulta dos resultados dos seus trabalhos.
- **Avaliador:** responsável por visualizar os trabalhos atribuídos, realizar
  as avaliações, registrar comentários e consultar avaliações realizadas.

## Principais funcionalidades

- Carga massiva de projetos;
- Carga massiva de professores;
- CRUD de professor;
- Cadastro de trabalho para avaliação;
- Cadastro de sessão de avaliação;
- Configuração dos critérios de avaliação;
- Associação de avaliadores aos trabalhos;
- Avaliação dos trabalhos;
- Consulta dos resultados gerais;
- Consulta dos resultados dos trabalhos do orientador.

## Modelagem do sistema

Nesta primeira etapa foram desenvolvidos os seguintes artefatos:

- Diagrama de Caso de Uso;
- Diagrama de Atividade do caso de uso "Avaliar trabalho";
- Diagrama de Classes;
- Diagrama de Estados;
- Matriz de Rastreabilidade.

Os documentos referentes à primeira entrega estão disponíveis na pasta
`/documentos`.

## Regras de negócio

- Um professor pode atuar como orientador e avaliador na mesma sessão.
- O avaliador somente pode avaliar trabalhos que tenham sido atribuídos a ele.
- A avaliação utiliza notas de 1 a 5 para os critérios definidos.
